# Support

Use [GitHub Discussions](https://github.com/ShiroKSH/rustferry/discussions) for usage questions and [GitHub Issues](https://github.com/ShiroKSH/rustferry/issues) for reproducible defects.

Include the RustFerry extension version, cargo-ferry version, extension-host environment, target platform, operation ID, and the sanitized failure summary from the **RustFerry** output channel. Never attach signing credentials, keystores, private keys, provisioning profiles, tokens, or complete environment dumps.
